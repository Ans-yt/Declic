# Administrative outlines

Source: DINUM / Etalab, derived from IGN ADMIN EXPRESS. Vintage 2025, generalised to 1,000 metres. These are orientation outlines, not cadastral or legal boundary measurements.

- https://etalab-datasets.geo.data.gouv.fr/contours-administratifs/2025/geojson/regions-1000m.geojson
- https://etalab-datasets.geo.data.gouv.fr/contours-administratifs/2025/geojson/departements-1000m.geojson
- Generator and source information: https://github.com/datagouv/contours-administratifs

Licence Ouverte / Open Licence 2.0: https://www.etalab.gouv.fr/licence-ouverte-open-licence/

Files include overseas territories in their actual geographic positions. Region dropdown entries follow the public Parcoursup catalogue. Boundary vintage and catalogue year are separate.
