# Déclic artwork

The wordmark, app icon, transparent notebook, three new stickers and annotation marks were supplied in the user's Déclic media kit. The existing four colored stickers were supplied earlier by the user. The original notebook illustration was generated earlier for Déclic and is used on the welcome page. The media-kit notebook is used on the dashboard.

Fraunces is self-hosted; its OFL license files are in `fonts/`. Application files use curated copies, so the original media-kit export can remain excluded from Git. No image-generation prompts are needed to run or build the app.
